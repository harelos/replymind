# ReplyMind CTA route map

| Surface | Visitor-facing CTA | Destination | Billing behavior |
|---|---|---|---|
| Funnel entry | Read the guide | Assigned story or seven-reasons advertorial | None |
| Story advertorial | See how it handles a real reply | Assigned long or short sales page | None |
| Seven reasons after reason 2 | Show me the reply workflow | Assigned sales page | None |
| Seven reasons after reason 5 | See the full workflow | Assigned sales page | None |
| Seven reasons after reason 7 | Choose ReplyMind Pro | Assigned sales page | None |
| Sales hero/body/final | Start ReplyMind Pro | Assigned checkout style | Paddle monthly/annual selection |
| Checkout primary | Start ReplyMind Pro | Paddle.js inline/overlay checkout | Real ReplyMind Pro price ID |
| Checkout secondary | Install the free version | Published Chrome Web Store listing | No payment |
| Success | Open ReplyMind in Chrome | Published Chrome Web Store listing | Post-purchase onboarding |

No CTA promises a result, hides a price, or routes Dopamodoro-style pages to web checkout. ReplyMind ends at real Paddle checkout; the free action remains secondary at the final decision.
